This repository contains the source code for [Fuzzy Dice Game](fuzzy-dice-game.onrender.com), a static Javascript website. The website is hosted on Render under a free tier, which means that it can take ca. 10 seconds to load.

I made this game to learn how to deploy container environments and how it interacts with a backend database. But naturally, this is a fan-game and I hope you enjoy it. It is possible to break the game if you're wise and lucky!

Also, I  made this with the help of AI tools (GPT, Claude, Mistral Vibe), for coding assistance and improving code quality only. The game rules and underlying mechanics are mine.
